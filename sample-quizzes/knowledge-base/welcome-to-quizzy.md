## You are set up

Quizzy stores your library in the **working directory** you chose. Quiz files are `.json` in that folder. Notes like this one live in `knowledge-base/`.

## Everyday flow

1. **Home** — browse quizzes, start an attempt, favorite or archive items.
2. **During a quiz** — answer, flag hard items, finish to see your score.
3. **Knowledge** — open linked notes while you study; create new notes for anything you want to remember.
4. **Mistake Log & History** — revisit weak questions and past attempts.
5. **Goals** — set a target score for a quiz and track progress.

## Add more content

- **Import quiz file** on Home for JSON you already have.
- **How to import** explains the format and includes an AI prompt template.
- **QuizHub** (optional in Settings) lets you browse and download curated quizzes and notes.
